# DAVOS

Interactive airborne perception research demonstration for IT / UBI. Explore detection, tracking, and dynamic visual object search in a simulated drone scene.

Open `index.html` through a local web server, or visit the [live demo](https://kailashhambarde.github.io/davos/).

This is a research visualization. The boxes and trajectories illustrate scene geometry and workflow; they are not measured detector or tracker results.
